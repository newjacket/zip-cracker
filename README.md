# ZIP压缩包密码恢复工具

## ⚠️ 合法用途声明

本工具仅用于**恢复自己遗忘密码的压缩包**。禁止用于破解他人加密文件、窃取数据等任何非法用途。使用者需自行承担法律责任。

## 功能特性

- **三种攻击模式**：字典攻击、掩码攻击、字符集暴力破解
- **多进程加速**：自动利用所有CPU核心
- **实时进度**：显示速度、进度百分比、预计剩余时间
- **支持AES加密**：兼容传统ZipCrypto和AES加密的ZIP文件
- **结果自动保存**：破解成功后自动保存密码到文件

## 关于32位复杂密码

**纯暴力破解32位复杂密码在计算上是不可行的：**
- 94种可打印字符的32位组合数 ≈ 10^63
- 即使每秒尝试10亿次，也需要约 10^46 年
- 这超过了宇宙年龄的无数倍

**实用方案：**
1. **字典攻击**（最高效）：使用常见密码字典
2. **掩码攻击**：知道密码部分结构时（如前4位是pass，后4位是数字）
3. **短密码暴力**：仅适用于6位以内的简单密码

## 使用方法

### 1. 字典攻击（推荐）

```bash
python zip_cracker.py -f secret.zip -m dict -d passwords.txt
```

### 2. 掩码攻击

知道密码部分结构时使用，效率极高。

**掩码规则：**
| 符号 | 含义 | 字符数 |
|------|------|--------|
| `?d` | 数字 0-9 | 10 |
| `?l` | 小写字母 a-z | 26 |
| `?u` | 大写字母 A-Z | 26 |
| `?s` | 特殊符号 | 32 |
| `?a` | 全部可打印字符 | 94 |
| 其他 | 固定字符 | 1 |

**示例：**
```bash
# 密码是 pass + 4位数字  (pass0000 ~ pass9999, 共1万种)
python zip_cracker.py -f secret.zip -m mask -k "pass?d?d?d?d"

# 密码是 3位小写字母 + 123  (aaa123 ~ zzz123, 共17576种)
python zip_cracker.py -f secret.zip -m mask -k "?l?l?l123"

# 密码是 1位大写 + 3位数字 + 固定后缀  (A000abc ~ Z999abc)
python zip_cracker.py -f secret.zip -m mask -k "?u?d?d?dabc"
```

### 3. 暴力破解（仅短密码）

```bash
# 纯数字 1-6位
python zip_cracker.py -f secret.zip -m brute -c digits --min 1 --max 6

# 大小写字母+数字 1-4位
python zip_cracker.py -f secret.zip -m brute -c alphanum --min 1 --max 4

# 自定义字符集
python zip_cracker.py -f secret.zip -m brute --custom-charset "abc123" --min 1 --max 5
```

**字符集预设：**
- `digits` - 纯数字
- `lower` - 小写字母
- `upper` - 大写字母
- `letters` - 大小写字母
- `alphanum` - 字母+数字
- `all` - 全部可打印字符

### 4. 性能调优

```bash
# 指定进程数（默认=CPU核心数）
python zip_cracker.py -f secret.zip -m dict -d dict.txt -w 8

# 调整批量大小（影响进度更新频率，默认500）
python zip_cracker.py -f secret.zip -m dict -d dict.txt -b 1000
```

## 常见问题

**Q: 为什么破解速度这么慢？**
A: AES加密的ZIP每次验证密码都需要进行密钥派生（PBKDF2），计算量大。这是加密算法的设计，目的就是防止暴力破解。

**Q: 支持RAR文件吗？**
A: 目前只支持ZIP格式。RAR文件建议使用 cRARk 或 John the Ripper。

**Q: 字典文件从哪里来？**
A: 可以从网上搜索"常用密码字典"下载，或使用 crunch、cupp 等工具生成定制字典。

**Q: 破解到一半能暂停吗？**
A: 可以按 Ctrl+C 停止，但当前版本不支持断点续传，下次需要从头开始。
